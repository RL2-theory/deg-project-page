Abstract

Cross-embodiment offline reinforcement learning offers a potential way to address the limited availability of robot interaction data. It aims to learn a shared policy from datasets collected across robots with different physical configurations. However, these differences can lead to conflicting updates during shared actor training. Existing Embodiment Grouping (EG) uses fixed groups based on robot morphology and does not update their assignments as actor gradients change. We introduce Dynamic Embodiment Grouping (DEG), which periodically combines morphology and current actor-gradient information to refresh groups and compute soft robot contributions to sequential group updates. Across 16 simulated robots, we compare 31 experimental configurations that vary grouping, gradient processing, and policy architecture under a common evaluation protocol. In the evaluated grouping comparisons, soft assignments yield higher mean returns than hard assignments when morphology and gradients are combined; this ordering reverses for gradient-only grouping. Across five seeds on the evaluated 70% Suboptimal Forward dataset, DEG achieves a mean return of 52.79, 4.51 points higher than static EG (48.28), and a standard deviation of 2.13, compared with 5.88 for static EG. However, this improvement is not consistently observed on expert and replay datasets, suggesting that DEG's effectiveness depends on the data regime being evaluated.

Method

Static Embodiment Grouping (EG) trains one actor shared by all robots. It groups robots by morphology, then updates the actor once per group. DEG keeps the same actor and value-learning objectives and changes how robots contribute to each actor update.

  1. Regroup. The main configuration starts with four morphology-based groups. At each successful refresh, it combines a fused Gromov–Wasserstein (FGW) dissimilarity over gradient-augmented morphology graphs with pairwise gradient dissimilarity. Ward clustering forms the new groups. Refreshes are attempted every 5,000 iterations after warmup.
  2. Weight contributions. Each robot receives a weight for each group based on its affinity to the members. Before the first refresh, the weights are uniform.
  3. Update the shared actor. Each iteration computes every robot’s gradient at the same parameters. A shared Adam optimizer applies the weighted group gradients sequentially in a fixed order. Refreshed weights take effect in the next iteration.

DEG-Freeze retains the weights from its first successful refresh. DEG-Collapse continues to regroup but uses the mean of the group gradients for every actor step.

How to read the configuration names

Configuration names combine the choices below. For example, EG Dynamic Direct Soft means gradient-only regrouping with soft routing on the standard shared architecture.

Grouping

EG Static groups fixed from robot morphology, using FGW, a body-structure distance between robots.

Dynamic (FGW) groups refreshed every 5K steps from gradients combined with that structure distance.

Dynamic Direct groups refreshed from gradient similarity alone.

GeoEG uses geometry-weighted distances to define fixed groups or initialize dynamic groups.

Uniform no groups. Group-Uniform one group per update step.

Routing

Hard (default) each robot belongs to one group.

Soft every robot contributes to every group with weights. DEG uses soft routing.

Group count

M = 4 in the main setting; M = 7 in the group-count comparison.

Gradient add-ons

PCGrad projects conflicting gradients within hard groups or across robots before soft aggregation.

PCGrad Norm normalizes gradient magnitudes before projecting.

Inter-PCGrad applies PCGrad to the group-level gradients.

Architecture add-ons

Per-Robot Heads separate actor and critic output heads; actor-only and critic-only variants are also tested.

MoE an adapted mixture-of-experts actor with learned robot-specific gates.
